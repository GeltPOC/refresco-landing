# FreshBurst Landing Page

Landing page moderna y colorida para promocionar el refresco FreshBurst.

## Stack

- **Next.js 16** con App Router
- **TypeScript**
- **Tailwind CSS v3**

## Secciones

1. **Navbar** — Navegación fija con blur backdrop
2. **Hero** — Titular llamativo, CTA, ilustración SVG de lata animada y selector de sabores interactivo
3. **Beneficios** — 4 tarjetas de características con stats nutricionales
4. **Visual del producto** — Display de las 4 latas con selector de sabor
5. **Testimonios** — Opiniones de usuarios sobre fondo degradado
6. **CTA** — Formulario de suscripción para muestra gratuita
7. **Footer** — Links, sabores y redes sociales

## Características

- Selector de sabor interactivo que cambia el color del hero
- Lata SVG animada (float animation)
- Formulario de email con feedback visual
- Totalmente responsive
- Sin dependencias externas más allá de Next.js y Tailwind

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
